## Pinned contract and bounded change

WiiCompiled remains `a135beb201042b20f390c6695ca6b26768820fb4`.
GXLoadTexObj at `0x80170F2C` takes the guest object in r3 and map ID in r4.
The new object is `0x80384500`, map 0. Its exact eight words are
`00000190 00000000 00300C03 0001C22A 00000000 00000003 00000000 00010202`.
Pinned extraction yields physical backing `0x00384540`, 4x4 IA8, no mipmaps,
clamp/clamp, linear/linear filtering, zero LOD/bias, bias clamp false,
edge-LOD false and anisotropy 1x. User data and TLUT are zero; the non-CI
flag is set. The payload bytes are neither captured nor substituted.

Aurora GXTexture.cpp sizes IA8 in 4x4, 32-byte tiles. Its texture_convert.cpp
also routes IA8 through the tiled IA8 decoder. The bridge validates the whole
32-byte backing range before resolving the host pointer and calling the real
GXInitTexObj, GXInitTexObjLOD, GXInitTexObjUserData and GXLoadTexObj. It reuses
the existing host-object map, forwards the approved dimensions/format, and
derives edge-LOD from descriptor bit 8 exactly as pinned extraction does.

The original 832x456 RGB565 descriptor remains accepted with its full
758,784-byte backing and edge-LOD true. Every other descriptor/map/object
variation still reports `GX_LOAD_TEX_OBJ_UNPROVEN_DESCRIPTOR` and aborts.
An unknown descriptor now reports size zero (no proven accepted size), rather
than the unrelated RGB565 size. Accepted-descriptor failures and successful
load diagnostics report their own actual required size.

The existing post-load mirror is preserved: `GXData+0x5FC |= 1` and
`GXData+2 = 0`. Both guest CPU bytes and the guest descriptor remain unchanged.
Headless mode checks the same descriptor/backing and publishes guest mirror
updates without issuing native GX calls. No new dispatch mapping or shared
trait header change is needed.

## Executable validation

`scripts/test-gx-texture-load.sh` builds the real texture bridge, native trait,
CpuContext, Aurora types and Switch memory implementation under ASan/UBSan in
rendered and headless modes. Independent field encoding builds the descriptors;
deterministic synthetic bytes fill the payloads. The host allocation seam
does not emulate Horizon aliases. GX sinks verify forwarding, rather than
native FIFO or GPU decoder behavior. Existing syntax seams avoid unrelated
desktop dependencies while preserving pinned GX declarations. Linker section
collection removes unrelated bridge entry points from this host executable.

Tests check both accepted loads, exact native call ordering/arguments,
full-size host pointer resolution, repeated host-object reuse, distinct
object identities, CPU/descriptor/payload preservation, guest mirror changes
and durable load-status sizes. Each descriptor word, map ID and object identity
variation must still stop. Uninitialized memory, a truncated descriptor,
unmapped or 31-byte IA8 backing, and a one-byte-short RGB565 backing must
report and SIGABRT before GX calls. Null host pointers and thrown native init
calls must also stop before guest mirror publication. Null CPU pointers have
no effect. Both executable contracts pass.

The fast-track link probe retains the direct texture-load trait and bridge;
the build workflow runs this contract alongside the existing scalar, indirect
and ambient contracts. Two legacy unused constants in the large texture
translation unit are tolerated by the host compiler; other warnings remain
fatal. Rendered syntax, all workflows, the private rendered build and exact-NRO
hardware progression remain required.
