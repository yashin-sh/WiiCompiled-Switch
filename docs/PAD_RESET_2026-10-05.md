# PADReset pinned success contract — 2026-10-05

The [fresh motor run](HARDWARE_RESULTS_2026-10-05_PAD_CONTROL_MOTOR_PAD_RESET_FRONTIER.md)
reaches PADReset `0x801AF0DC`, mask `0x70000000`, dispatch 619288 at 112.024
seconds, LR `0x80523848`. This candidate implements that observed boundary;
its return requires a fresh console run.

## Pinned contract

Pinned WiiCompiled `runtime/src/hle/input/pad.cpp` forwards the full uint32
mask to Aurora PADReset and returns `1` for true / `0` for false. Pinned
`aurora-main/lib/dolphin/pad/pad.cpp` implements PADReset as an unconditional
true return with an ignored mask. Its checked build copy is byte-identical.
No initialization, controller reset/polling, memory access, callback, input
mapping or library-state mutation is performed by that pinned function.

The Horizon bridge preserves this exact native contract: every mask is accepted,
r3 becomes 1, and all other CPU bytes and PAD/WPAD state are preserved. Null
CPU input is ignored. This does not implement a physical controller reset or
pre-port the neighboring PADRecalibrate API.

The diagnostic stage is `RMCP01_PAD_RESET`. `fast-track-pad-reset.txt` records
`pinned-reset-pass`, the full eight-digit hexadecimal mask, return value 1 and
`controller_reset=none`. Repeated unchanged masks do not reopen the SD file;
mask transitions are recorded and failed opens remain retryable. SD failures
do not alter the pinned guest return.

## Validation

The executable production-trait/bridge contract passes **5,223 cases** with
ASan, fatal UBSan and LeakSanitizer. It covers both initialization states, the
observed mask, zero/all-bit masks, every single bit, all sixteen high-nibble
controller masks, 2,048 deterministic full-width masks per state, complete CPU
preservation apart from r3, preserved library state, null input, exact observed
report bytes, failed SD opens, transitions and 1,000 repeated polling calls.
The contract links without guest Memory or an input backend, so an accidental
dependency on either fails linking.

The eighteenth host suite and the dedicated synthetic probe/production symbol
retention are wired into CI. Both rendered and synthetic AArch64 compile
configurations include the new source. Remaining local/remote/private-build
checks are in progress; no new NRO is accepted or deployed yet.
